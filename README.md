# Wind Farm Modeling from Scratch

This project is a continuation of an online course on the basics of wind energy and wind turbine and wind farm modeling. The course offers a concise and organized method, ranging from fundamentals to Python implementation. The goal is to enable you to model wind turbines and design wind farm simulations for any location on Earth.

### Key Learnings from this Course:
- **Introduction to Wind Energy**: Get acquainted with the fundamentals of wind energy and wind turbines.
- **Python Programming Fundamentals**: Acquire Python programming skills to compute wind turbine output power and investigate wind data.
- **Wind Turbine Modeling**: Develop a model of a single wind turbine with realistic parameters such as power curves and efficiency.
- **Wind Farm Simulation**: Learn how to upscale your turbine model to simulate a wind farm and optimize its performance.
- **Practical Data Handling**: Graph, download, and examine historical wind speed data from actual sources to determine energy output for given locations.

### What Makes This Course Special: - **Hands-on Coding**: The program enables you to learn how to code everything from scratch rather than utilizing existing libraries or codes so that you fully understand each process.

- **No Prerequisites**: We begin with no prerequisites at all, even the fundamentals of Python programming so that you are well-equipped to learn wind turbine modeling.

- **Comprehensive Learning**: By the end of the course, you'll have the capability to model single wind turbines and entire wind farms, visualize results, and examine wind energy data for any point on Earth.
